ABOUT

01 / 05

Record MEMORYは、音楽を中心に、バンド、アイドル、声優、ライブ、映像、写真など、さまざまな表現を通して、人と人、アーティストとファンがもう一度出会える場所をつくる、営利を目的としないインディーズ・クリエイティブプロジェクトです。

01

Re-Memory

過去の記憶をもう一度記録し、形を変えながら新しい記憶へつなげていくこと。

02

R = Our Memory

再び出会えた瞬間も、これから生まれる新しい瞬間も、すべてを「私たちの記憶」として残していく。

03

もう一度、出会う

あの日叶えられなかったことにもう一度挑戦すること。今まで知らなかった誰かと、新しい瞬間を共有すること。

PROJECT

02 / 05

One project, One new memory. 音楽を中心に、アーティストとファンが新たな記憶を共有できるプロジェクトを企画しています。

LIVE PROJECTS
